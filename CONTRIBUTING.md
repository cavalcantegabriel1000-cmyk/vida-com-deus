# Contribuindo para Vida com Deus

Obrigado por estar interessado em contribuir para o projeto Vida com Deus! 🙏

## Como Contribuir

### 1. Fork o Repositório
Clique no botão "Fork" no GitHub para criar uma cópia do repositório na sua conta.

### 2. Clone o Repositório
```bash
git clone https://github.com/seu-usuario/vida-com-deus.git
cd vida-com-deus
```

### 3. Crie uma Branch
```bash
git checkout -b feature/sua-feature
# ou para correção de bugs
git checkout -b bugfix/descricao-do-bug
```

### 4. Faça as Mudanças
Edite os arquivos necessários e teste suas mudanças localmente.

### 5. Commit suas Mudanças
```bash
git add .
git commit -m "Descrição clara das mudanças"
```

### 6. Push para a Branch
```bash
git push origin feature/sua-feature
```

### 7. Abra um Pull Request
Vá para o repositório original e abra um Pull Request com uma descrição clara das mudanças.

## Padrões de Código

### TypeScript
- Use tipos explícitos sempre que possível
- Evite `any`
- Use interfaces para estruturas de dados

### React
- Use componentes funcionais
- Use hooks quando necessário
- Mantenha componentes pequenos e focados

### Styling
- Use Tailwind CSS para estilização
- Siga a paleta de cores do projeto
- Mantenha o design responsivo

## Relatando Bugs

Antes de relatar um bug, verifique se já não foi reportado. Se encontrar algo novo:

1. Use um título descritivo
2. Descreva o comportamento exato do bug
3. Explique o comportamento esperado
4. Inclua screenshots se aplicável
5. Mencione sua versão do Node.js, npm e navegador

## Sugestões de Melhorias

Sugestões são bem-vindas! Por favor:

1. Use um título descritivo
2. Forneça uma descrição detalhada da melhoria
3. Liste exemplos de como a melhoria funcionaria
4. Menção se você teria interesse em implementá-la

## Código de Conduta

Este projeto e todos os seus participantes estão comprometidos com manter um ambiente acolhedor e respeitoso. Esperamos que todos os contribuidores:

- Sejam respeitosos
- Incluam pessoas de diferentes origens
- Focam no que é melhor para a comunidade
- Mostrem empatia com outros membros da comunidade
